# PoE2 Overlay with Claude

**Path of Exile 2 아이템 분석 오버레이 + 크래프팅 지식베이스**

인게임에서 아이템을 `Ctrl+C` 하면, 클립보드의 아이템 텍스트를 읽어 현재 빌드
(Ice Strike 마셜 아티스트 멍크) 슬롯별 타겟과 대조해 게임 위에 띄워주는 가벼운
오버레이입니다. 여기에 Claude와 함께 리서치·정리한 **0.5 패치 크래프팅 자료**가
묶여 있습니다.

> 🛡️ **안전**: 오버레이는 **클립보드를 읽기만** 합니다. 게임 메모리 접근·자동 입력·
> 파일 인젝션이 전혀 없어 GGG 서드파티 정책상 안전 영역입니다
> (시세 툴 Awakened PoE Trade와 동일한 "Ctrl+C → 클립보드 읽기" 방식).

---

## ✨ 기능

- **클립보드 자동 감시** — 인게임에서 아이템 `Ctrl+C`만 하면 버튼 없이 자동 분석
- **빌드 타겟 대조** — 슬롯(장갑/무기/반지/…)별로 노려야 할 옵션 중 ✅충족 / ⬜비어있음
- 아이템 이름·희귀도·ilvl·요구레벨·원문 옵션 표시
- 항상 위(topmost) 반투명 창, 드래그 이동·접기, 창 위치 자동 저장
- **정밀 판단은 Claude에게**: `Ctrl+C` 한 텍스트를 붙여넣으면 아래 크래프팅 자료 기준으로
  "어떻게 크래프팅/가성비/시세"까지 판단

---

## 🚀 실행

1. Python 설치 (tkinter 기본 포함) — https://www.python.org/downloads/
2. `poe2_overlay.pyw` 더블클릭
3. PoE2 그래픽 설정을 **테두리 없는 창 모드(Windowed Fullscreen)** 로 변경
4. 인게임에서 아이템에 커서 → `Ctrl+C` → 오버레이에 자동으로 분석 표시

자세한 사용법: [README_실행방법.md](README_실행방법.md)
