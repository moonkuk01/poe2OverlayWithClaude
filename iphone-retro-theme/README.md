# 레트로 몬스터 RPG 스타일 아이폰 테마

컬러 휴대용 게임기(GBA) 시절 몬스터 RPG 느낌의 픽셀 아트 테마입니다. 몬스터, 주인공, 아이콘은 모두 직접 그린 오리지널이에요.

## 구성 (`output/`)
| 파일 | 설명 |
|---|---|
| `icons/*.png` | 앱 아이콘 16종 (512×512, 32×32 도트) |
| `wallpaper_home.png` | 홈 화면: 마을, 수풀, 연못, 몬스터들 (1290×2796) |
| `wallpaper_lock_<몬스터>.png` | 잠금 화면: 야생 몬스터 배틀 화면, 몬스터 4종 버전 |
| `preview_home.png` | 홈 화면 적용 예시 |

오리지널 몬스터: MUSHLING(버섯), DRIPPY(물방울), FLITTER(박쥐), EMBERPUP(불꼬리 강아지)

## 아이폰에 적용하기
1. 이미지를 아이폰 사진 앱에 저장합니다. (AirDrop, iCloud Drive, 카톡 나에게 보내기 등)
2. **배경화면**: 설정 → 배경화면 → 새로운 배경화면 추가 → 사진에서 잠금 화면/홈 화면 이미지를 각각 고릅니다.
3. **아이콘**: 단축어 앱 → `+` → "앱 열기" 동작 → 앱 선택 → 공유 버튼 → **홈 화면에 추가** → 아이콘을 눌러 "사진 선택"으로 PNG 지정 → 이름 입력 → 추가
4. 원래 아이콘은 길게 눌러 → 앱 제거 → **홈 화면에서 제거**를 고릅니다.

## 내 이미지 넣기
`custom/` 폴더에 투명 배경 PNG를 넣고 다시 생성하면, 홈 화면 마을에 그 이미지가 함께 배치됩니다.
```bash
pip install pillow
python3 make_theme.py
```
- 몬스터 도트는 `sprites.py`에서 문자 그림으로 수정하거나 추가할 수 있어요.
- 아이콘은 `make_theme.py`의 `ICONS`에서 수정하거나 추가할 수 있어요.
