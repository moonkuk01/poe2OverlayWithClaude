# PoE2 아이템 분석 오버레이

인게임에서 아이템을 **Ctrl+C** 하면, 클립보드의 아이템 텍스트를 읽어
현재 빌드(Ice Strike 마셜 아티스트) 슬롯별 타겟과 대조해서 게임 위에 띄워줍니다.
클립보드를 **읽기만** 하므로 GGG 정책상 안전합니다 (메모리 접근·자동입력 없음).

## 실행 방법

1. Python 설치 (이미 있으면 생략) — https://www.python.org/downloads/ (tkinter 기본 포함)
2. `poe2_overlay.pyw` 더블클릭 → 오버레이 창이 뜹니다
3. PoE2 그래픽 설정을 **테두리 없는 창 모드(Windowed Fullscreen)** 로 변경
   (전체화면에서는 오버레이가 게임에 가려집니다)

## 사용법

1. 인게임에서 아이템에 커서를 올리고 **Ctrl+C**
2. 오버레이가 **자동으로** 파싱해서 표시 (클립보드 감시 중)
   - 자동으로 안 뜨면 `🔍 지금 분석` 버튼 클릭
3. 결과 화면:
   - 아이템 이름·희귀도·ilvl·요구레벨·슬롯
   - **빌드 타겟 대조**: 이 슬롯에서 노려야 할 옵션 중 ✅충족 / ⬜비어있음
   - 아이템 옵션 원문

- **창 이동**: 상단 제목줄 드래그 · **접기**: `—` · **종료**: `✕`
- 창 위치는 `~/.poe2_overlay_config.json` 에 자동 저장

## 정밀 분석 (크래프팅 / 시세)

오버레이는 "빌드 타겟에 맞는지" 빠른 대조용입니다.
**어떻게 크래프팅할지 / 시세가 얼마인지** 같은 정밀 판단은 아이템 텍스트(Ctrl+C 한 것)를
클로드에게 붙여넣으세요. 참고 자료:

- [POE2_크래프팅_가이드_0.5.md](POE2_크래프팅_가이드_0.5.md) — 범용 크래프팅 방법 (통화·에센스·오멘·Desecration 등)
- [POE2_클래스맞춤_멍크_IceStrike.md](POE2_클래스맞춤_멍크_IceStrike.md) — 내 빌드 슬롯별 타겟

## 파일 구성

- `poe2_overlay.pyw` — 앱 본체 (단일 파일, 외부 라이브러리 불필요)
- `test_core.py` — 파서/타겟대조 테스트 (`py -3 test_core.py`)

## 빌드 타겟 바꾸기

다른 빌드용으로 쓰려면 `poe2_overlay.pyw` 상단의 `BUILD_SLOT_TARGETS`
딕셔너리(슬롯별 노릴 옵션 키워드)와 `BUILD_NAME` 을 수정하면 됩니다.
